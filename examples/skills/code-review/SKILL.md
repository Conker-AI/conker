---
name: code-review
description: Review a proposed change for correctness, regressions, and missing verification.
---

Review the supplied code or change. Prioritize concrete defects and the behavior
that would trigger them. Distinguish verified findings from things to investigate.
For each finding, explain the consequence and suggest the smallest useful fix.

Do not invent line numbers, test results, repository contents, or tool access.
If there is not enough evidence to identify a defect, say what is missing.
Keep the review concise and focus on findings that affect behavior.
